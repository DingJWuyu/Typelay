# Windows MVP milestone 与验收

不是“全部 UI → 底层”的顺序。M1 工程起点已落盘，但本轮没有运行 C# 编译或 Windows 验收，**M1 尚未通过**。

| 阶段 | 实际交付目标 | 进入下一阶段的验收条件 |
|---|---|---|
| M1：安全内核 + Windows fixture | 状态机、快照、UTF-16、候选版本、写回拒绝、原生输入 fixture、独立测试入口 | 新 C# 工程构建成功；核心 runner 成功；真实 Win32 fixture 全文/选区/caret/emoji/CRLF/拒写/敏感字段零读取通过；提交始终 0 且正向计数器可触发；记录源码指纹和实际运行环境。当前代码已编写，以上运行门槛未执行。 |
| M2：首条真实本地闭环 | 用户会话 App、隔离模型 worker、极小非激活 WPF Overlay、真实输入观察与全局键盘链路 | CPU-only 的真实模型有输出；输入期间无抢焦点；物理 Tab 写回且不提交；无候选/生成中/失败/变更源与目标时 Tab 正常到达应用；自己的写回不立即重翻；无网络推理回退。不能用测试内固定字符串当本地模型通过。 |
| M3：人工编辑 + Edge 普通文本 | 持久编辑控件、显式焦点组合、原控件返回确认、UIA 有限 provider | 原生与 Edge 分别完成：点击→连续输入→拖选 Delete→继续 Backspace/输入无需再点→Tab 回原控件→下一 Tab 接受人工译文；鼠标返回同样有效；焦点离开整体销毁；原选区外原文保持，caret 正确；浏览器 input/textarea 分开记录。 |
| M4：真实 IME + 竞态/故障门槛 | 对已选 IME/provider 的完整安全认证、超时隔离、实际事件 epochs、边界矩阵 | 微软拼音组合、候选、提交、取消、Tab/Esc、已有候选时新组合均正确；Unknown 不翻译；浏览器源/目标/选区变化拒写及 Tab 放行通过；worker 卡死/崩溃不阻塞输入、不误重试；异步吞 Tab 和写回竞态有明确支持边界/解决证据。 |
| M5：托盘 / 基础设置 / 限定发布 | Quick Panel、基础设置、真实模型状态、排除、单实例、开机启动选择、安装/卸载、窗口移动/DPI/滚动 | 原型 IA 与文案一致；空框/暂停不打扰；Auto 与交换不暗改文本；排除即时生效；Explorer 重启/用户退出清理；双屏不同 DPI、滚动越界、断网、无全文日志通过；仅发布已经认证的具体矩阵。 |

## 风险工作不等到 M4 才开始

M1 构建与 native fixture 建立后，马上开展**新 MVP 内**的最小 WPF 焦点宿主及外部 IME 能力诊断：关注能否稳定点击编辑、是否能返回同一字段、哪些 provider 真有组合状态。它们随 M2 的最小浮层一起集成，不等所有 UI 或所有设置完成才发现技术冲突。

M3/M4 是签署对应完整行为的验收门槛，不表示此前忽略焦点与 IME。若 Edge provider 只能读不能安全写/确认选区，标记该能力不支持，不能用“Edge 基础已通过”掩盖整条路径缺失。

## M1 的明确非验收项

M1 没有模型、WPF 浮层、UIA 通用发现、全局 Hook、Tray、Settings。M1 测试内为 WritePlan 提供固定英文属于测试数据，不能称为真实翻译；fixture IME 状态注入不是拼音实测；定向 API 调用成功不是物理 Tab 成功。

## 每次验收的证据约定

记录：run_id、源码指纹、构建/测试退出码、.NET SDK/runtime、Windows build、应用版本、IME profile、DPI/显示器配置、场景 ID、明确 expected/actual、pass/fail/not-run/blocked。仅测试文本可出现在经明确标识的 fixture 录屏；普通诊断不默认收集全文。

可以部分验收，但不能把失败/未执行改写为通过。验收报告描述实际代码版本；若验收中改了源码，旧测试结果不能自动签署新版本。

## 直接接手顺序

1. 解压新工程，在 Windows 运行 `dotnet build TypeLay.slnx -c Release`。修复编译与测试问题只针对新 MVP。
2. 执行核心 runner 与 `tools/validate.ps1 -Native`，保留全部输出；有失败先定位，不使用旧 PoC 的“通过”替换结果。
3. M1 通过后，只加最小 App/模型 worker/浮层；同时拿真实源控件做焦点进入/返回、真实拼音能力验证。
4. 未解决异步吞 Tab / 跨进程写入竞态之前，不为任意应用打开全局接受。
