# Test changes

先读根 AGENTS.md。测试的价值是阻止错误行为再次出现，不是数量、行覆盖或目录齐全。

## 选择可观察边界

- behavior/TypeLay.Core.Tests：Session/AcceptanceGate/WriteSafety 的公开操作序列，尤其预览与接受资格分离、输入版本、人工草稿、字段策略、UTF-16 选区映射和拒绝条件。时间显式传入，不用 sleep。
- contracts/TypeLay.Protocol.Tests：真实帧序列化与非法输入拒绝。标准 xUnit Facts/Theories 由 dotnet test 发现，不维护自制注册表或测试执行器。
- worker/：协议、文本结构和真实隔离进程的启动失败。无模型依赖；翻译器替身只能验证结构保留，不能证明语言质量或真实推理成功。
- e2e/test_distribution.py：解压实际 ZIP 到含空格和中文的新目录，再启动真实 App/Broker/worker 入口。通过公开管道验证生命周期、鉴权、拒绝和隐私，不调用 Broker 私有成员。
- e2e/TypeLay.Native.Tests 与 fixtures/support：真实 Win32 fixture 的旧适配器测试。不是生产 UIA，不是物理按键，也不是中文输入法验收。

## 修复顺序

1. 在最接近原用户路径的可用环境运行一次可失败的回归，并记录失败现象。
2. 提出可证伪的原因；一次只改变一个相关因素。不能先修生产代码再编造“之前必然失败”的结论。
3. 用同一测试证明修复，再跑受影响的邻近行为与工作区检查。
4. 删除临时探针，保留回归。测试环境不足时标注未测，不放宽安全条件或静默跳过要求。

端到端测试必须有超时和自身资源清理。不得终止不属于测试的进程、改真实用户设置或下载模型。不能为了通过而增加任意等待、无上限重试或代码关键字断言。

只在已有边界无法观察问题时增加新的接口。删掉实现形状测试前确认行为回归已经覆盖其真实意图。测试名称说明用户行为或协议结果，不说明实现细节。
