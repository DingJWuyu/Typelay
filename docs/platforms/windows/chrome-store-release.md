# 准备 Chrome 商店发布材料

<a id="chrome-商店发布准备"></a>

本页用于把 Windows 扩展的实际发行内容转成商店材料。当前[发行配置](../../../src/windows/browser/connection.chromium.json)仍没有正式扩展 ID 或商店链接，仓库也没有可据此确认的已发布条目。下文文字是待核对草稿，创建条目、上传、接受协议和提交审核仍需所有者明确确认。

先核实际扩展 ZIP 和桌面候选，再填写用途、权限与隐私，最后准备截图和安装说明。商店说明只承诺该候选已验证的能力；当前源码编译或 CfT 软件测试不能代替品牌 Chrome 的安装验收。

## 发布对象与前置条件

[Windows 打包脚本](../../../eng/windows/dev.ps1)从 Windows manifest、共享 `background.js`、`content.js`、图标与字体生成 `browser/chromium`。该目录是 Windows 扩展来源，扩展 ZIP 根必须直接包含 `manifest.json`。桌面 App、模型、profile 和日志不进入扩展 ZIP。[Chrome 官方打包要求](https://developer.chrome.com/docs/webstore/prepare)

Windows 与 Linux manifest 不同，Linux 另加载富文本桥接脚本。Windows 条目不能借共享 JS 文件声明已经支持 Linux 富文本或其它未加载能力。

扩展依赖另行安装并运行的 TypeLay Windows x64 客户端和本地模型。当前源码默认准备 Index，也保留 Argos 与可选 Hy；商店功能以实际候选的可用方向为准，不沿用旧“只有中英 Argos”的描述，也不把研究方向或未放行质量能力写入宣传。

正式身份就绪后，发行配置必须固定该 ID 和一致的商店详情链接，再重建并验证安装、接入、移除。CI profile 的随机开发 ID 不能成为正式身份。

## 商店文字草稿

名称沿用[当前 manifest](../../../src/windows/browser/manifest.chromium.json)：**TypeLay local input**。发布者可在后台选择匹配的生产力分类，并以实际后台选项为准。

简短描述草稿：

> 连接本机 TypeLay，在支持的网页输入框中预览翻译或按快捷键替换文字。需要另装桌面客户端和本地模型。

详细描述草稿：

> TypeLay 将本机翻译带到网页输入框。先安装并运行 TypeLay Windows 客户端、准备本地模型，再在客户端的“应用支持”中明确接入扩展。
>
> 在具备相应能力的普通文本框中，你可以自动查看译文并主动接受，也可以按需预览或直接翻译选区。直接替换不会代你发送消息或提交表单。输入文字通过浏览器本地消息通道交给本机 TypeLay，翻译使用已安装的本地模型。
>
> 当前 Windows 接入面向顶层 HTTP/HTTPS 网页的文本或搜索 input 和 textarea。Chrome 内部页、新标签页、嵌套 frame 与富文本编辑器不在本版支持声明内。密码和可识别敏感字段会受限制；测试开发预览时请使用非敏感文字。翻译质量取决于已安装模型，重要内容请核对。
>
> 你可以暂停 TypeLay、移除本地连接，或在 Chrome 管理站点访问权限和卸载扩展。仅安装扩展不会下载模型或启动桌面客户端。

提交前应按实际候选核对上述能力，尤其是接受、直接替换和安装流程。未通过的功能应从本次条目承诺中移除，不能用说明草稿替代产品验收。

## 单一用途与权限说明草稿

单一用途草稿：让用户通过本机 TypeLay，对当前支持的网页输入框进行本地翻译预览和主动替换。

| 当前声明 | 可用于提交的说明 |
| --- | --- |
| `nativeMessaging` | 扩展通过 `org.typelay.browser` 与本机 TypeLay 交换已校验的字段请求、译文与操作结果，网页脚本不运行模型。 |
| HTTP/HTTPS 顶层 content script | 用户在不同网站的普通输入框中使用翻译。脚本观察焦点、字段属性和原次快捷键，经客户端批准后读取字段，再按用户操作预览或替换。它不抓取整页或执行整页翻译。 |
| 字体 web-accessible resources | 页面中的扩展界面使用包内字体，不从远端获取界面字体。该资源声明不是独立的浏览历史或网络拦截权限。 |

当前 `all_frames=false`，manifest 没有 `tabs`、`history`、`cookies`、`storage`、`debugger` 或网络拦截权限。HTTP/HTTPS 匹配仍代表广泛页面访问，不能写成只在点击扩展图标后才访问。权限变化须先修改并验证实际包，再更新材料。[官方单一用途与权限说明](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)

## 隐私披露技术草稿

发布者应根据以下实现事实形成公开政策，并按后台当前定义填写。这里描述数据路径，不代替所有者的政策承诺或认证。

[content.js](../../../src/shared/browser/content.js)观察焦点、选区、输入事件、IME 和字段属性。安全元数据包括标签、占位文字、元素 ID、无障碍属性与部分祖先角色，可能包含用户信息，因此不能声称完全不读取页面数据。[background.js](../../../src/shared/browser/background.js)读取 sender URL 以核 HTTP/HTTPS，当前路由不转发完整 URL、页面标题或浏览历史。

客户端先批准字段元数据，页面再按输入法、版本与期限读取受支持字段的文字和选区。捕获可能包含整个字段，超长正文是在读取后拒绝。自动模式可随正常输入持续读取和翻译；按需模式由快捷键启动翻译，但不能承诺快捷键前没有字段读取。

执行脚本随包分发，后台只连接本地 native host。当前翻译路径使用本机模型，没有将翻译正文发送给云翻译 API 的实现。模型准备需要网络下载，Chrome 更新扩展与网页自身的网络活动不属于本地推理承诺。

字段观察、请求与译文在进程内存中保留到操作结束。设置、模型和连接注册保存在用户数据位置。暂停或断连会撤销当前资格；移除连接不会删除模型、设置、网页已填文字或用户保存的诊断，也不承诺安全擦除所有内存副本。

浏览器路径的可选 `TYPELAY_TRACE` 只记录有界状态、布尔、序号、计数和时间，不记录正文或字段元数据。这个结论只限已核日志路径，未来新增遥测或崩溃上报需要重新核对。复制译文会写系统剪贴板，接受译文会改原网页字段，网页仍可按自身逻辑读取或上传该字段。

后台数据类别须根据最终实现核对网站内容、用户活动和用户填写信息。**本地处理仍须披露数据使用。** 隐私政策需说明收集、用途、披露和控制，并与界面及条目一致。[官方本地处理说明](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)、[隐私字段要求](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)

## 素材与提交前核对

1. 核实际 ZIP 中的 16/48/128 PNG 图标。图标来自现役 TypeLay SVG，维护者可用 `python eng/shared/generate_browser_icons.py --check` 和脚本注明的工具版本核对，发行构建只复制已有资源。
2. 准备至少一张真实候选截图，尺寸为 1280×800 或 640×400。128×128 商店图标和至少一张截图是官方必需项；440×280 宣传小图为可选，不能写成必需。截图使用合成非敏感文字，原型或测试报告不能冒充当前界面。[官方图片规范](https://developer.chrome.com/docs/webstore/images)
3. 确认发布者身份、公开支持联系方式、隐私政策 URL 与长期桌面下载入口。Actions artifact 有期限，不适合作为商店长期下载地址；联系方式由所有者提供。
4. 所有者批准建条目后，将实际 ID 和链接固定到发行配置。用同一候选验证品牌 Chrome 安装、权限确认、桌面接入、网页翻译和移除，保留真实结果。
5. 给审核者提供可执行的桌面安装、模型准备与标准网页步骤，说明需要本地程序而无需云翻译账号。后台要求的额外材料或条款由所有者确认。
6. 提交前复核 ZIP 清单、manifest 版本、权限、脚本行为、可访问的隐私 URL 与条目文字。材料就绪、已提交审核和已上线分别记录，不能合并为发布完成。
