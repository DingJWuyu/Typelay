# TypeLay Windows 预览

这是 Windows x64 本地输入翻译工具的开发预览，尚未完成通用输入支持与完整产品验收。

**重要限制：Windows 原有实验性 Tab 写回默认关闭。** Windows 通用 UI Automation 的读取、校验和写入不能组成原子操作，仍有覆盖并发输入的风险。测试实验写回时，只使用已备份的非敏感文本。直接替换与 Linux 合作输入路径各自依赖经过校验的目标能力，不通过开启开关扩大兼容性。编译和自动化测试通过不等于真实中文输入法、物理 Tab 或所有应用都已验收。

## 安装与启动

在本仓库 Actions 中打开 `TypeLay checks` 已核对的运行，下载对应提交的 artifact，取出其中的 `TypeLay-Windows-preview.zip`，完整解压后双击 `TypeLay.exe`。当前候选及仍未通过的项目见下方；不要单独移动可执行文件。`Start-TypeLay.cmd` 是备用入口。

升级前先从托盘退出旧 TypeLay，再把完整 ZIP 解压到新目录启动。App 与 Broker 必须来自同一个包；旧版本的输入组件会被连接校验拒绝，不会降级读取或写回。若“应用支持”提示连接检查失败，先退出并从完整安装目录重开；仍失败时重新解压完整包，不要只替换其中一个程序。

预览包自带 .NET 运行时，不需要 SDK、Python 开发环境或源码。第一次使用时，在设置中明确同意安装本地翻译组件与模型。模型安装后，推理在本机 CPU 上运行。组件和设置存放在 `%LOCALAPPDATA%\TypeLay`，不会作为源码或发布包提交。托盘菜单提供设置、练习与退出入口。

普通输入框是产品目标，不是按应用维护的支持名单。未知输入法状态只允许只读预览；密码、敏感字段、终端和代码编辑器不能通过弱化安全限制来“扩大支持”。

当前源码在显式唤醒已接受、首次读取输入框失败或抛出异常时，按原目标和本次命令给出一次提示。请保持焦点后主动重试；此提示不代表读取成功率已经改善，也不会自动重试。

托盘修改设置遇到保存错误时，会保留上次确认的状态并显示提示，模型状态刷新不会抹掉错误。检查目录权限或磁盘空间后，重新选择原控件即可重试；收到成功结果才清除提示。

### 自有输入框练习

模型准备好后，在“应用支持”点击“试一试”，或使用托盘练习入口。入口遵循当前模式：自动模式练习自动预览、接受、修改译文与回源；按需模式直接练习当前唤醒/直接替换快捷键。练习使用当前合法的接受与退出配置，不因无修饰功能键而要求切换模式。已保存的 Ctrl+功能键已通过自有练习软件输入链，公开组合选项尚未开放。暂停或模型未就绪时先完成准备。

自有自动练习已在[真实 Windows 软件输入检查](https://github.com/DingJWuyu/Typelay/actions/runs/38998367114)中通过本地模型预览、首次 Tab 接受、点击修改译文、Tab 与鼠标回源、第二次 Tab 精确接受人工稿，以及完成后的撤权确认、保存提示偏好和关闭；保存结果已重新读盘核验。译文可以先显示，浮层出现接受提示后才表示当前操作就绪。第一次回源不写原框，重新确认后才能接受人工稿；这项授权仅属于本次自有练习框，不打开全局实验写回。物理按键、实际输入法及长期可靠性仍需验证；该检查整体仍有其它失败。

按需练习使用独立普通输入框和合成示例。默认按 `Ctrl+Shift+F9` 查看译文，原文不变；在输入框按一次 `Ctrl+Shift+F10` 重新翻译原文并直接替换，不发送或提交，也不接受浮层人工草稿。安全状态未知时仍拒绝。本次进度只计算真实预览和直接替换的 Verified 回执，配置变化、重新开始或关闭会清除进度；重新开始保留输入。

关闭练习不会自动恢复模式或覆盖后来的设置；只有完成全部自动步骤并成功保存，才记录教程提示偏好。使用预览包前须核对其源码版本，整套桌面验收仍有失败。

## 暂停与恢复

在常规设置或托盘暂停后，TypeLay 清除当前会话的原文、译文、草稿和接受资格，不再采集正文或翻译。仅在可确认安全的输入框旁显示“已暂停 / 点击恢复”；只读取字段身份、位置及安全属性。密码、敏感、只读、已排除或无法确认的字段不显示入口，仍可从常规设置恢复。

点击恢复只启用 TypeLay，保留当前工作模式、语言和快捷键。按需模式恢复后仍需使用已配置的唤醒快捷键。焦点或字段已经变化的旧入口会失效；设置保存失败时保留暂停并说明失败。下方候选已通过受控桌面的暂停入口与恢复检查，真实设备和输入法仍需独立验收。

## 模型准备失败后的恢复

当前源码默认仍一次准备中文与英语两个方向。需要节省模型空间时，可展开准备区详情，只选中文→英语或英语→中文；已有单向安装可用“补齐另一方向”增加缺项，修复不会删除已安装方向。自动识别先判断源语言；同语无需翻译，缺少所需方向时提示补充模型，直接替换不会写入原框。下方候选已通过真实单向安装与补齐的模型接口检查，以及相关设置交互回归；该安装检查没有操作输入框或触发 F10。

在“应用支持 → 准备翻译”保留失败原因和一个重新准备入口，区分网络、磁盘空间、组件完整性、文件访问、运行环境和未知原因。只有用户主动暂停才显示“继续准备”；下载或自检超时属于失败。展开“安装诊断”可查看固定错误类别和阶段，不包含输入文字、原始异常或本地路径。

组件完整性失败会清除已确认损坏的对应下载；若文件占用或访问限制挡住清除，先按提示解除阻塞，再重新准备。不要手工清空整个数据目录。运行自检失败不会推断所有模型包损坏。Windows 将候选组件放入独立安装代，自检和实际模型握手成功后才切换；准备失败保留仍可用的旧安装，不能恢复已经失效的旧进程状态。只有实际模型进程就绪后才显示可用。

下方候选包含该恢复流程，已验证隔离下载失败、损坏缓存、用户暂停与自检失败的分类和恢复入口。

当前源码把准备卡的主要操作按真实阶段排列：准备、暂停、继续或失败重试优先；模型就绪且没有待恢复任务时突出“试一试”，修复作为次级操作。输入服务连接事实与操作错误分别保留。[对应桌面验证](https://github.com/DingJWuyu/Typelay/actions/runs/38650565562)已通过未准备、已安装未就绪、就绪、暂停过渡、失败不被旧就绪状态覆盖及草稿焦点选区回归；浅深色窄窗截图中主要操作完整可见。安装成功后启动模型的卡片阶段尚未单独完成 GUI 验收。该历史检查未全绿；下方当前候选已包含此准备卡改动。

## 工作模式与按需操作

在“设置 → 常规 → 工作模式”选择模式，重启后保留。升级时没有此偏好的用户仍使用自动模式，已有应用排除项不会因新增偏好失效而被清除。

| 模式或操作 | 行为 |
| --- | --- |
| 自动模式（默认） | 聚焦后按原有规则显示语言胶囊、生成译文与接受译文。两个新增快捷键均不启用。 |
| 按需模式 | 正常聚焦、输入时不显示翻译 UI，也不自动运行翻译。 |
| 唤醒翻译 UI：默认 `Ctrl+Shift+F9` | 为当前输入框开启持续翻译体验；空框显示语言胶囊。正常编辑 TypeLay 译文不算离开；转到其他输入框后结束，返回原框也需要重新唤醒。 |
| 直接翻译并替换：默认 `Ctrl+Shift+F10` | 有选区时只处理选区，否则处理当前输入框文本。一次性操作，不显示预览、不需要 Tab、不发送或提交。 |

“设置 → 快捷键”共用一次保存操作管理唤醒、直接替换、接受和退出。接受默认 `Tab`，退出默认 `Esc`，也可分别选择无修饰的 `F1-F24`；编辑译文时第一次接受键只返回原输入框，重新确认后第二次才尝试写回。唤醒和直接替换仍使用带修饰键的组合，当前不支持 F12。非法或重复设置不会部分保存；保存失败保留草稿，关闭时默认继续编辑。被其他应用占用的按需组合键不会启用，状态显示在设置中。上述操作不改变工作模式或自动解除暂停。

应用排除列表与四个快捷键共用“保存修改”。添加、移除及切页保留草稿，保存失败可继续修改或重试；关闭时默认继续编辑，明确放弃才丢弃未保存内容。保存排除时仅应用本次增删，保留其它入口对未修改项的更新。

此接受/退出配置是冻结规格 §18 的首个增量，尚不支持任意修饰键组合，也不能据此宣称所有冲突处理已经完成。仅在目标实际确认当前配置后才允许按键接受或人工编辑；旧组件、配置不一致时保留允许的只读预览。当前源码顶部保留“译文就绪”等简短状态，编辑入口由译文控件的悬停、键盘焦点和无障碍名称呈现；进入编辑后显示“编辑中”。可编辑不表示已取得写回许可。本节列出的候选已包含这些设置，使用其它构建时须核对源码版本。

直接替换绑定触发时的原输入框和文本。翻译期间可切换输入框或应用，任务不会仅因焦点变化取消；结果只尝试写回原控件，不抢回焦点，不修改后来聚焦的输入框。原目标失效、内容冲突、输入法状态不明确或无法确认结果时，不进行有风险的重试。操作状态沿用托盘快速面板反馈。

**直接替换的当前兼容范围是 Windows x64 中通过运行时校验的原生系统 `Edit` 控件。** 需要未被应用替换窗口过程、身份仍有效且能完成原文校验的控件。不支持该事务的浏览器、富文本或自定义控件不会回退到 UIA `SetValue`、模拟按键或抢焦点写回。普通只读预览控件仍可按需唤醒，但这不赋予写回权限。实现依据与边界见 [ADR-0002](https://github.com/DingJWuyu/Typelay/blob/trunk/docs/adr/0002-on-demand-and-direct-write.md)。
