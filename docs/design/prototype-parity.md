# 原型一致性验收清单

按本页方法核对真实界面与已确认原型。任务状态、历史失败和原件由 [Issue #22](https://github.com/DingJWuyu/Typelay/issues/22)维护；该票保留迁移前各项证据、原期限与关闭条件。本页不记录某次提交的通过结论。

## 基线与证据边界

设置、托盘与首次设置遵循[设置原型](TypeLay_Tray_Settings_Prototype.html)。浮层与练习遵循[浮层原型](TypeLay_UIUX_Prototype.html)。字体、材质与动效同时核对[设计系统](system/README.md)。产品行为与能力范围分别见[产品基线](../product/README.md)和[能力边界](implementation-gaps.md)。

先确认被测提交、发行包、组件与模型身份，再从实际窗口取得证据。软件注入、受控端口、未封装构建和原生桌面各自说明范围；生成截图后逐张检查。字体未加载的原型图只用于结构和几何参考。

### 保留的产品约束

保留 Windows shell、niri 接入、真实模型同意与安装事务。同语和人工路径、已保存但当前不可用的语言、旧 Argos/Hy 明确选择继续有效。原型列表过滤另一端不授权删除既有能力。

原型中的 macOS 窗口按钮、菜单栏、模拟桌面、场景选择器、预设译文和虚构下载进度仅用于演示。

N06 更多语言、N07 简洁/口语、N08 设备选择、N09 常驻、N10 模型更新和 N11 软件更新按[能力边界](implementation-gaps.md)显示真实禁用状态。自然/正式风格、另述、术语、字体、教程与动效不属于这些例外。模型资格遵循[发布策略](../engineering/model-runtime.md#模型能力边界)。

### 语言与风格页分项验收

下列细项用于 S04/S05，不新增任务编号。

- 核对 900×660 基准窗口中的方向按钮、交换按钮与卡片几何。方向按钮为 250×44，交换为 36×36；缩放环境另记实际 scale。
- 分别用名称、自称和代码搜索源/目标列表，核对中英浅深、无结果、选中勾、即时保存与重开后的值。
- 用真实公开输入验证 Up/Down/Enter/Esc、外点取消和返回 anchor。核对旧查询、隐藏行、同步重开及用户移焦后的迟到回调，保持原期限。
- 未就绪模型保留真实说明与门控。自然/正式不因原型演示而假启用，简洁/口语按仅界面范围处理。
- 打开并退休独立语言窗口后切换字体，核对实际系统字体设置与已存角色。私有样式不覆盖宿主或其它窗口偏好。
- 暂停广播后核对 query、选区、当前选项与保存资格。异步 remap 不抢回用户已经转移的焦点，不用循环 grab_focus 或延长期限通过。
- 核对 popover 的 280 宽、30 高搜索框、6px anchor 间距及窗口边缘向上翻转。GTK3 的同色实底不等同背景模糊，也不代替其它消费者验收。

## 验收关闭方式

默认截图使用 Claude/15/clay，并明确指定 zh-CN 或 en、light 或 dark。再分别验证 sans/system、13/19、其它 accent、solid 和三态 motion。每页覆盖默认及实际交互状态；每个浮层消费者覆盖 idle/loading/valid/edit/long/menu/stale/error/paused。

记录窗口尺寸、DPI/scale、字体来源、实际源码身份与操作结果。使用现役证据目录保存原件，并在对应 Issue 中报告 passed、failed 或 not-run。缺少接受提示是否正确，须结合当时真实资格判断。

只有已知差距取得目标界面证据、未观察项补齐且对应回归通过，才能关闭该项。安装成功、截图、编译或其它平台结果不能替代本项用户流程。任务状态更新到 Issues，不向本页追加轮次日志。
