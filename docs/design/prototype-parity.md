## 页面闭环顺序

先完成当前双端负责人正在处理的完整页：Windows 与 Linux 均为语言与风格。随后按下表补齐每页的默认、搜索/编辑、失败、取消/重开状态，再以真实窗口对照后转下一页。`P0` 是缺交互/错误状态/能力缺口，`P1` 是明显结构和文案不一致，`P2` 是仍须完成的视觉动态；优先级不表示允许遗留。

责任缩写：`W` Windows 设置/托盘/首次设置 owner；`L` Linux GTK 设置/托盘 owner；`WO` Windows 浮层/练习 owner；`C` GTK3/GTK4/Qt6 合作浮层 owner；`B` 共享浏览器 owner；`S` 共享偏好/运行时 owner；`F` 离线字体 owner。实际负责人由开发状态页维护。
