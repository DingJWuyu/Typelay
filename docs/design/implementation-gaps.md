# 新界面的能力边界

本页记录新原型中本轮只提供界面、不实现底层的功能。设置项必须明确显示尚未提供或不可用，不写入无效配置，不显示虚构下载、更新成功或硬件加速效果。界面重构不改变输入、焦点、输入法和写回安全条件。

| 编号 | 界面 | 当前真实能力 | 后续需要实现 |
| --- | --- | --- | --- |
| N06 | 更多语言与翻译方向 | 当前 Index / Hy 产品目录为 8 种语言、14 个以中文为中心的方向；安装内容决定实际可用方向 | 对每个新增方向完成模型支持、结构保护、语言质量及两端生命周期验证 |
| N07 | 简洁、口语风格 | 当前已定义的风格只有自然与正式；可选风格仍受质量发布条件约束 | 推理参数与提示设计、保义和稳定性验证 |
| N08 | 自动、CPU、GPU、NPU 设备选择 | 当前正式模型运行路径是 CPU | 硬件发现、可分发推理后端、资源与失败恢复策略 |
| N09 | 模型常驻内存 | 当前生命周期由现有 worker 管理，无此用户开关 | 明确加载、释放、退出与资源上限，验证设置效果 |
| N10 | 模型版本更新 | 已有模型安装、暂停、继续、修复；没有原型展示的独立版本更新服务 | 可信版本来源、下载校验、切换和失败回退 |
| N11 | 软件检查更新与自动更新 | 当前通过项目发行包交付 | 更新来源、完整性校验、安装与失败恢复流程 |

## 原型中的演示环境

macOS 菜单栏、红黄绿窗口按钮、模拟聊天应用、场景控制器与预设译文只服务原型演示，不属于 Windows/Linux 产品界面。模型版本、容量和下载进度使用真实安装信息；不复制原型的虚构数据。快捷键冲突展示只反映实际校验和平台注册结果，不声称能扫描并归属任意应用的快捷键。

## 已有底座的质量要求

术语表、按应用风格与换种说法的管理界面可以连接现有存储和会话接口，但模型应用能力仍须满足相应模型、语言方向与版本的质量条件。保存规则不等于该模型已承诺应用规则。界面必须区分“已保存”与“当前模型尚未开放”，不得用新外观替代质量验证。

## 原生呈现的已知差异

- 字体随包提供 Inter 与 Source Serif 4 的原始静态版本；CJK 字形仍使用平台回退，未捆绑全部 Noto CJK。相同文案在不同系统上可能换行不同。
- 搜索语言会进入独立的原生选择界面，并先退休原会话。它不冒充仍聚焦在原输入框，不保留旧接受许可；与原型内嵌菜单的持续呈现仍有差异。
- GTK4 合作浮层保留已验证的即时尺寸变化，未为了弹簧动画引入已知编辑焦点丢失风险。GTK3 / Qt6 只对安全长文高度使用可中断弹簧，宽度和胶囊切形仍为即时变化。
- GTK / Qt 跨应用浮层没有原型的背景模糊，使用可读的暖纸半透明回退；逐词模糊、写回飞入、拖动以及菜单拆分仍有差异。GTK 的私有包字体注册要求 Pango 1.56 或更新版本，不满足时使用系统字体。
- WPF 保留单一真实编辑控件与无障碍值语义；逐词模糊入场、跨进程向源框落入的装饰动画尚未等同原型。动画不足不能解释为已完整复刻。

Linux 的全局暂停通过目标 niri 的显式系统键绑定调用 `typelay --toggle-pause`。界面录制与保存快捷键不等于所有 Wayland 合成器都自动注册成功，不修改用户已有合成器配置。
