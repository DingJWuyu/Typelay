按需翻译练习

设置布局原则：先显示当前准备状态、一个明确下一步和必要风险提示；完整接入说明不得挤掉首屏主要操作。此页为设计示例，不是客户端验收截图。

先准备本地模型。Windows 的“试一试”打开真实练习框；Linux 的“选择接入方式”先显示接入步骤，按实际状态确认连接后再打开练习。使用窗口显示的预览快捷键生成译文，随后使用直接替换快捷键完成替换。只有本次练习框的真实结果才推进两步进度。

状态示例：等待连接 → 已生成预览 → 已验证直接替换。重新开始只重置进度，保留输入。Linux 练习窗口在准备期间撤下旧进度，确认本次输入框后再显示重置结果，请按窗口第 1 步重新生成预览。关闭窗口不算完成，完整 Tab 与人工编辑教程仍单独验收。

Linux 接入：检查冲突 → 记下原输入法的恢复方式（或确认此前未运行）→ 自行退出后重新检查 → 确认连接。结束后先关闭练习、移除受管接入，再按原方式手动恢复；检测到运行不代表恢复方式已验证。

排除的应用

每行一个可执行文件名，保存后生效。密码、敏感字段及无法确认输入法状态的控件不会读取或替换。

此处同步 Linux 当前四页布局，仅演示现有控件的分组与草稿。风格持续/应用覆盖、换种说法、显式术语表和搜索式多语言仍是产品缺口，没有占位页面。Windows 与 Linux 均须分别完成真实桌面和视觉验收。
