按需翻译练习

设置布局原则：先显示当前准备状态、一个明确下一步和必要风险提示；完整接入说明不得挤掉首屏主要操作。此页为设计示例，不是客户端验收截图。

先准备本地模型，再使用准备区之后的“试一试”打开真实练习框。使用窗口显示的预览快捷键生成译文，随后使用直接替换快捷键完成替换。只有本次练习框的真实结果才推进两步进度。

状态示例：等待连接 → 已生成预览 → 已验证直接替换。重新开始只重置进度，保留输入；请先输入新的原文。关闭窗口不算完成，完整 Tab 与人工编辑教程仍单独验收。

Linux 接入：检查冲突 → 记下原输入法的恢复方式（或确认此前未运行）→ 自行退出后重新检查 → 确认连接。结束后先关闭练习、移除受管接入，再按原方式手动恢复；检测到运行不代表恢复方式已验证。
