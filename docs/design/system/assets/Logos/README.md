# Logos

- `typelay-mark.svg` — the mark: two rounded layers, the front one solid. Ink `#141413` outline and clay `#d97757` fill on light grounds; on dark grounds, swap the outline to `#f4f3ee`. In the menu bar it is drawn single-ink in the text colour.
- `typelay-app-icon.svg` — the app icon: a white mark on a clay gradient squircle (`#e48a69 → #c4573a`). Use it in About, onboarding and the tray header. Never recolour the squircle by accent setting.
