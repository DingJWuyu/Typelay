# TypeLay

TypeLay 是一层贴在任何输入框上的本地翻译。界面只做三件事：告诉你现在的语言方向，给出一句译文，等你按 Tab。设计系统的一切都服务于「安静、贴身、可信」。

两个交互原型直接从这套 token 构建：`TypeLay_UIUX_Prototype.html`（翻译浮层）和 `TypeLay_Tray_Settings_Prototype.html`（设置、托盘、首次设置）。源文件是 `src/tokens.css`，由 `build.py` 内联进每个原型；改 token 时，这里和 `tokens.css` 一起改。

## 文案

- **能删就删。** 不写标语、辅助说明和次要标签。如果一个屏幕必须靠说明才能看懂，就改布局，不加字。
- **只在状态改变 Tab 的含义时说话。** 浮层的阶段标签只有一两个词：`翻译中`、`更新中`、`已修改`、`仅预览`。译文可以接受时，只显示 `Tab 接受`。
- **说结果，不说过程。** 用 `已替换，未发送`，不用「正在为你写回输入框……」。
- **中英双语对等。** 每条文案都有 `zh-CN` 和 `en` 两份。英文菜单项用 Title Case（`Translate Again`），设置项用 sentence case（`Open at login`）。
- **语言名不手写。** 一律来自 `Intl.DisplayNames`：界面语言显示语言名，列表右侧显示该语言的自称（`日本語`）。
- **方向标签固定格式：** `Auto → EN`、`中 → EN`。Auto 模式不会因为检测到中文而改写成 `中`。

## 字体

Claude 官网的气质：衬线标题与正文，配干净的无衬线界面。字体都用免费的近似字体。

| 角色 | 拉丁字母 | 中文 | 日文 | 韩文 | 用在 |
| --- | --- | --- | --- | --- | --- |
| `--font-display` | Source Serif 4 | Noto Serif SC/TC | Noto Serif JP | Noto Serif KR | 页面标题、首次设置 |
| `--font-content` | Source Serif 4 | Noto Serif SC/TC | Noto Serif JP | Noto Serif KR | 译文、原文输入、术语 |
| `--font-ui` | Inter | Noto Sans SC/TC | Noto Sans JP | Noto Sans KR | 控件、标签、菜单 |

**不硬编码。** 组件只用角色变量。角色变量在 `:root, [lang]` 上按语言重新解析，所以：

- 界面语言切换后，`<html lang>` 改变，界面字体随之改变；
- 译文元素带 `lang=<目标语言>`，译成日文就自动用日文衬线，译成英文就用 Source Serif；
- 外观 → 字体有三档：`Claude`（衬线 + 无衬线）、`无衬线`（全部 Inter / Noto Sans）、`系统`（-apple-system / Segoe UI / PingFang / 微软雅黑）。

译文字号是用户设置（13–19px，默认 15），行高 1.55。token 文件只能表达一组字体栈，按语言区分的映射以本表和 `tokens.css` 为准。

## 颜色

暖调中性色加一个强调色。默认强调色是陶土色 `accent-clay`（#d97757），可在外观里换成 ocean、sage、iris、graphite。

- `accent` 只用于填充：开关、滑块、进度、选中环、浮层圆点。它在白底上只有 3:1，**不能当文字色**。
- 文字需要强调色时用 `accent-ink`（浅色 5.3:1，深色 6.1:1）。
- 白字底色用 `accent-strong`（4.9:1）：主按钮、菜单高亮行、已发送气泡。
- 状态只用圆点和极少的文字：`green` 表示就绪，`amber` 表示需要注意，`red` 表示失败。不用整块红色。
- 层级靠 `ink → ink-2 → ink-3` 三级墨色区分，不靠颜色区分。过期译文降为 `ink-3`，并带一道 `shimmer` 扫光。

## 材质

浮层、托盘面板、菜单栏和菜单是 **玻璃**：`glass` 底色，加上 `blur(28px) saturate(180%)`、内侧 0.5px `glass-edge` 高光，以及外侧 0.5px `glass-border`。窗口和卡片是实色。

打开「降低透明度」后，所有玻璃都改用 `glass-strong`，并去掉模糊。

## 形状

- **胶囊是产品的标志。** 空闲时的浮层就是一枚胶囊（`radius-pill`，圆角等于高度的一半）。展开后成为 `radius-overlay` 18px 的面板。两者是**同一个对象**，不是两个组件。
- 设置项按 macOS 的分组卡片排列：`radius-md`，行高 44px，0.5px `line` 从左侧 14px 起画分隔线。
- 窗口 18px，侧栏是悬浮在窗口里的内嵌玻璃卡片（四周留 8px）。

## 动效

动效只属于视觉层：不推动布局，不抢焦点，也不能授予权限。权限永远同步撤销，比如开始更新的那一刻，`Tab 接受` 立刻消失。

- **形变用弹簧，不用定时曲线。** 浮层宽、高、圆角由可打断的弹簧驱动；新的目标出现时保留当前速度，所以「边展开边长高」会连贯地衔接。
  - 变大：`spring-grow`（340/26），带轻微回弹。
  - 收回胶囊：`spring-settle`（560/40），不晃。
  - 首次出现：从 0.9 倍缩放弹出（`spring-appear`）。
- **内容锚在左下角。** 语言胶囊跟着面板生长的边缘移动，看上去就是胶囊自己长成了面板。
- **译文逐词浮现。** 每个词从模糊 7px、下沉 0.32em 的状态还原，间隔 `word-stagger` 24ms。更新时只有变化的词播放动画，前缀不动。拉丁文按空格分块；中日文按 `Intl.Segmenter` 分词，标点粘在前一个词上，保证行首不会出现「，」。
- **接受。** 译文向输入框落下并淡出，输入框边缘闪一次强调色，面板弹回胶囊。
- **减少动态效果。** 跟随系统，也可手动设置。开启后，所有弹簧直接跳到终点，不做模糊，也不错开。

## 图标

使用 1.6px 描边、24 网格、圆角端点的线性图标，与文字同色。设置侧栏的图标放在 22px 彩色圆角方块里，白色图标，参照 macOS 系统设置。标志由两层圆角矩形组成：后层描边，前层实心，表示「叠在上面的一层」。见资源组 Logos。

## 组件

- **TranslationOverlay**：胶囊 / 面板 / 编辑 / 暂停四种形态，以及语言胶囊、阶段标签、`Tab` 提示、悬停才出现的「展开」和「更多」。
- **SettingsGroup**：分组卡片、行、开关、分段控件、键帽。
