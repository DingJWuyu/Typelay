# 界面设计基线

两份 HTML 是当前用户确认的视觉与交互基线：

- [设置与托盘](TypeLay_Tray_Settings_Prototype.html)
- [翻译浮层与使用引导](TypeLay_UIUX_Prototype.html)
- [设计系统](system/README.md)：字体、色彩、间距、材质与动效令牌，以及组件和标识资源。

实现保持 Windows WPF 与 Linux 原生界面，复用共享业务、模型和安全规则。原型的演示桌面和预设数据不进入产品；本轮仅前端的能力见[实现缺口](implementation-gaps.md)。设计系统中的在线字体加载仅用于原型预览，产品资源须支持离线运行。

每个真实界面分别验证亮色/暗色、缩放、长文本、加载、错误、编辑、取消和重复操作。原型可点击不代表底层能力已实现，自动化成功不代替目标桌面验收。
