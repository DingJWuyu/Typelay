# Verification protocol

修改测试、排障或声明验收结果时读本文件和 tests/AGENTS.md。

## 自动化层级

`dev.ps1 check` 验证构建、标准 xUnit 行为/契约测试、Python 行为/启动测试和格式/lint。
`dev.ps1 pack` 生成真实自包含 ZIP，再运行分发与进程 E2E。该流程不装模型、不打开用户文档、不通过假翻译器伪造 ready 状态。
`dev.ps1 native-e2e` 需要已解锁桌面，范围仅限旧原生 fixture。前置条件失败是未执行，不是通过。

测试失败时保留命令、提交 SHA、平台、退出码和最小失败输出。只使用合成测试文本。TRX 和临时包保留在 artifacts/；新证据不要重新提交到 docs/history/。

## 真实产品验收

以下项目需在实际 Windows 桌面单独执行并记录。默认只读优先，实验写回仅用备份的非敏感内容。

1. 完整解压，双击 TypeLay.exe，首次安装需明确同意；重复启动只留一个托盘；退出后 App、Broker、worker 和 hook 全部退出。断网后已装模型仍能推理。
2. 在教程之外的浏览器普通输入框与桌面应用中输入合成文本，验证真实模型候选、无抢焦点/页面挤压。无标签输入不能预先排除；失败控件如实记录。
3. 人工修改候选，观察原生光标、选择、粘贴与换行。第一次 Tab 只回源字段，下一次 Tab 才尝试接受；间隔不限速度，按住键不能提前接受。原文末尾追加与原文重写按冻结规格分别处理。
4. 使用真实微软拼音覆盖 composition、翻页、选词、取消、提交、Shift 切换和候选窗口期间点击浮层。DOM composition 和 SendInput 均不等于物理 IME/Tab 通过。
5. 对焦点切换、字段关闭/复用、源文本并发修改、Broker 超时/崩溃做拒绝测试。不得覆盖新文本、串写其它字段或提交表单。B-01 未关闭前不能勾选安全写回通过。
6. 对照 docs/reference 中已确认原型检查浅/深主题、100%-200% DPI、多屏负坐标、窗口移动、滚动、长文本和展开状态。记录截图、实际时延及设备条件，发现明显异常也要处理。

## 报告用语

分别写明：构建结果、行为/协议结果、分发/进程结果、模型推理结果、真实桌面交互结果、视觉结果。给出 passed/failed/not-run 及范围。

历史 PoC 的项目结项决策与报告“部分通过”并存，不重写事实。工程清理不关闭 B-01/B-02/B-03，不改变 ExperimentalWriteback 默认值，也不证明通用输入支持。
