# Domain docs

进行领域探索、命名或设计评审前，读根 GLOSSARY.md 与相关 docs/adr/ 文件；涉及 Linux 原生坐标时再读 docs/platforms/linux/adr/。本仓库是单一上下文，进程隔离不意味着多个业务领域。

在代码、测试、任务与假设中使用 glossary 的术语，特别区分 Preview、Candidate、WritePlan 和 AcceptancePermit。缺少术语时先判断是否真是本项目领域概念；通用编程术语不进入 glossary。

新发现与 ADR 冲突时明确指出冲突，不能默默改变已作决定。新 ADR 只记录实际解决的决定，不预填空文档；默认日期与证据必须来自本次操作。

仅文件缺失时继续工作，不为缺少模板建立额外工程任务。
