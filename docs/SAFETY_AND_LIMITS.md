# 安全阻塞项与范围

## B-01：UIA 校验与写回无原子性（开放，发布阻塞）

当前实现读取 `ValuePattern.Value` 并比较预期原文，再调用 `SetValue`。两个远程调用之间目标应用可能收到键盘输入、脚本更新或其它文本变化。前后多次核验和短期限会减少风险窗口，无法提供 compare-and-swap 原子保证。写后核验只能确认最终内容，无法恢复在竞态中丢失的新文本。

全局 Hook 还必须同步决定是否消费 Tab，而 Broker 校验异步进行。许可通过后到 Broker 实际执行前仍可能过期/变焦，出现拒写却已消费 Tab 的情况。当前实现不通过重新注入 Tab 来掩盖拒绝，避免注入到变更后的应用或干扰 IME。这意味着冻结规格“无有效接受条件时完整交还 Tab”尚未完全实现。

**控制措施：ExperimentalWriteback 默认 false，不颁发写回许可。** 开关开启时有明确用户警告，只允许受控、已备份测试内容。该开关不会改变问题的发布阻塞性质，也不会将安全责任转移成验收通过。后续需能与目标变化原子协调的后端或其它具备可论证语义的机制，并验证物理按键所有权。缩短期限、增加一次读或把测试写成 passed 均不足以关闭此项。

## B-02：实机验收未完整覆盖（部分完成，仍开放）

2026-10-07 已在本机完成 C# Release 构建、私有 SDK 启动脚本、自包含客户端与 Broker 启动、真实模型 CPU 推理。用户已实测 Edge 本地教程的单行、多行预览、整框及局部选区替换、浮层拖选和编辑后的两阶段 Tab。此前 Broker 文本范围访问冲突及浮层编辑焦点故障已修复并复测。逐项证据与范围见 `../VERIFICATION_STATUS.md`。

2026-10-10 使用正式客户端、独立 Broker 和真实模型，完成普通 Win32 Edit 的 45 字无标点持续回放、两个字段 100 次焦点切换、记事本整框 Tab 写回及编辑后的两阶段 Tab。实际微软拼音组合态保留 11 字已提交前缀的预览，提交后更新译文。字段回放由控件程序追加已提交字符，输入法按键由工具注入，均不等同于人工物理键盘。快速切换只验证预览绑定，不能证明写回竞态安全。浏览器启动被自动审批拒绝，当前桌面只暴露一块显示器，浏览器连续输入、独立网站与真实多屏 DPI 未验收完成。

验收对象是当前聚焦的普通输入框。不同应用、页面及控件是覆盖不同实现的样本，不是产品支持名单；某个样本受工具限制不能改变通用输入目标。详见 [最新记录](../VERIFICATION_STATUS.md)。

## B-03：通用输入与安全编辑后端缺失（开放，功能阻塞）

当前自动发现不限制应用进程或自然语言标签，但主要依赖 UIA Edit/明确可编辑 Document。缺少可靠输入法状态的普通字段现在可以从其值生成只读预览，不能进入人工编辑或 Tab 接受；没有 ValuePattern 的富文本也不能以整框 SetValue 写回。未暴露可编辑文本接口的自绘字段尚无捕获后端。这意味着“聚焦普通输入框即可连续翻译、编辑和 Tab 接受”的完整通用目标仍未达到。

本机普通 Win32 Edit 已通过正式 Broker 复现：TextEdit 不可用且 IMM 上下文为 0，快照为 Unknown。此次修复了因此完全没有浮层的问题，仍未取得可以安全写回的输入法证据。未知状态读取的普通字段值可能含尚未提交字符，只用于显示；已知组合态仍只读取已提交前缀。未知状态不会被伪装为 Clear，旧预览也不会因稍后状态恢复而自动升级为接受候选。

需要补齐能自动跟随焦点、可靠观测文本及选区、识别组合输入，并协调目标文本版本和按键所有权的编辑后端。应覆盖控件能力，而不是增加特定应用名单、要求标签或让用户判断输入框。B-01 同时仍须解决；增加等待、放宽 IME 检查、全局 Ctrl+A/V 或盲目重放 Tab 都不能作为关闭这些缺口的依据。

## 其它明确限制

控件元数据可能错误、缺失或被网页伪装。普通输入不再要求自然语言标签或特定应用进程，仍过滤已知敏感字段、密码、代码、终端和地址栏。不能宣称对伪装或缺失敏感元数据零误判。未做安全渗透或恶意页面测试。

文本限制为 8192 UTF-16 单元；模型单段限制为 384 token，超过限制拒绝，不静默截断。候选最多 512 解码 token；不存在模型语义正确性保证。结构保护使用分段保留 URL/邮箱/mention/编号/emoji/换行，可能影响相邻上下文的翻译质量。人工追加保留前缀，但不会全面重新融合语义。

UIA SetValue 写入整个字段的计算结果；选区外文字须与原快照完全相同。即使最终文字正确，应用的受控组件、撤销栈或事件派发仍可能有特定行为，未验证。只有可编辑 TextPattern、没有 ValuePattern 的富文本可预览，不进行整框 SetValue 降级。

接受许可在 Tab 按下时同步核验并消费，仍为 100 毫秒；收到已消费按键后，远程写回有独立的 250 毫秒执行期限，避免将短效按键许可误用为远程执行完成期限。派发前核验 Hook 输入与焦点版本，Broker 仍重新验证当前原文、选区、目标与输入法，并在最终远程读取后检查执行期限。此项解决期限误用，不能关闭 B-01 的跨进程非原子竞态。

没有磁盘翻译历史或正文日志；当前设置中保存进程排除名、语言和用户开关。推理子进程没有网络调用路径，但没有 OS 级网络隔离。系统崩溃转储、内存分页和杀毒产品的采集行为不在 TypeLay 的控制范围。

模型首次校验依赖 TLS 与运行组件供应商元数据；Argos 权重无上游固定摘要。包与应用未签名。生产分发前还需锁定完整二进制清单、核对模型许可证、代码签名、依赖供应链审查和针对实际下载的测试。
