职责不是实时活跃代理人数。Windows 问题组可分派并行负责人；Linux 由维护负责人处理现有功能，模型按独立方向推进，集成者统一合并、验证和发布。

| 责任线 | 当前下一动作 | 关闭条件 |
| --- | --- | --- |
| Linux 维护 | 验证新字段首次命令授权修正；保持安装维护，不做可选应用扩展 | 原 GIMP 单次首次唤醒及后续直接写回、撤销真实通过，完整 Linux 检查与包身份核对完成 |
| Windows 主开发 | 分别收敛自有源 Ctrl 首拒绝、浏览器 Tab 首拒绝及源线程按键边界 | 当前候选真实交互证据；安全边界成立后才讨论启用写支持 |
| Argos 调优 | 从真实 Settings 安装结果收齐归档尺寸/哈希，核磁盘准入后运行已准备的单因素对照 | 有效安装身份、固定输入/参数、原响应及退出证据 |
| Hy 调优 | 本轮 greedy/sampling 与保义 instruction 方向已收束，不重复扫相同配置 | 新假设或可用候选出现再开实验；当前结果不采用 |

### 翻译质量：有界实验，不盲目扫配置

- **Argos**：已有 beam2/beam4 证据未解决保义问题；当前 repetition penalty 1.05/1.0 单因素对照已准备，尚无新真实推理。项目启用中英双向，生态其他语言包不等于项目已支持。现安装空间准入约 8.657 GB，不能仅凭两包约 145 MB 压缩量降低；先取得固定归档身份、解压与保留量，再核是否可精确预留。
- **Hy**：实际普通翻译配置为官方 instruction+greedy、同 instruction+固定 seed sampling，以及 greedy+保义 instruction。前两者固定四句开发子集未明显改善；第三种覆盖八条已见难例，独立复核为 1 条明确严重错误、3 条未决、4 条未见严重错误。局部改善“尽量/只”，承诺误译和主体/范围风险未闭合；该方向收束，生产不采用。
- **证据边界**：完整八句旧 A 对照曾因 60s 截止中断，四句子集不能覆盖失败。环境重置后旧临时 A 原件丢失，派生对照不冒充原件；固定保义 B 的两份八句原始结果仍在持久目录，可重核。后续源码与不可再生证据只存持久工作区。
- **Qwen 候选**：官方 Qwen3-0.6B Q8_0 固定 revision 与 639,446,688-byte 文件已核 SHA；无需转换。嵌入与官方基础模板不同，但本次八条单用户、非思考分支实际渲染逐字相同。隔离短试固定一套官方建议采样与 seed，CPU2 / 地址空间2.5GiB / context1024 / output192 / 单请求60s / 总600s；失败停止，不改生产 provider。实际八条均以 EOG 完成、总 66.824s、进程退出确认，已见主体、数量、日期和承诺改变，独立语义复核进行中。执行成功不代表质量通过。
- **暂缓候选**：MADLAD 初始化已核超出现预算；M2M100 现有 CT2 支持不等于转换峰值可控，当前无可证明的 2.5GiB 转换路径，停止继续同条件转换研究。Qwen1.7B 官方 Q8 资源余量更紧，本轮不试；TranslateGemma4B 暂缓资源与条款核查。没有质量失败证据的候选不写成质量失败。
- **采用条件**：保存身份、参数、原响应、失败与退出证据，逐句检查否定、数量、主体、条件和承诺。已知八条只是开发集；局部改善最多支持继续验证，不直接改变默认。质量门见[产品共同缺口](../product/README.md#当前共同开发缺口)，执行方法见[测试协议](testing.md)。

## 每条线都要做的维护

1. **保持原行为与安全门。** 遵守 [AGENTS](../../AGENTS.md) 和产品基线；未知焦点、输入法、目标身份或结果继续拒绝/隔离。产品许可期限不放宽；外部环境准备与产品计时分开定义，不能靠重试、跳过失败或降低断言制造通过。
2. **代码、测试、文档一起收尾。** 修改行为时逐项判断相关旧测试：仍有效则保留，假设过时则更新，需求/接口真正退役才删除；修测试须说明保留了什么安全行为。失效接口、重复逻辑、无用文件和引用一起清理，遵循既有结构，不为整理重写全库。
3. **证据分层。** 每项写清“代码已实现 / 本地检查通过 / 当前提交 CI 通过 / 用户真机确认”。编译不等于 GUI，通过采集不等于质量合格；未运行不是通过。产品缺陷、测试问题、缺诊断、未支持功能和真机待验分别标记。
4. **失败后换取新证据。** 相同失败再次出现而没有新证据时，先写清假设、观察位置和下一判定条件，再运行；不盲目重跑，也不让一条线的问题停止无关工作。确需用户选择或授权时指出具体动作，其余独立工作继续。
5. **维护这个入口。** 集成负责人在实质结果或安排变化时更新基准、任务行和下一证据；问题关闭后删掉执行细节，将仍有用的限制放回平台说明。发布后核对候选提交、CI 和包一致，不新增阶段快照。README、平台说明和本页冲突时先按实际提交及证据校正，不能任选更乐观的结论。
