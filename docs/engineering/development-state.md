## 模型能力边界

新用户明确准备模型时，默认选择 Index；已有 Argos/Hy 安装与选择保留。术语仅对已登记的固定 Index profile 开放中英双向。风格、另述及组合质量门保持关闭。

本轮测试整治没有采集新的模型质量证据，也没有改变发布配置。安装成功、worker 握手、完成采集和语言质量通过分别判断。
