### 翻译质量：有界实验，不盲目扫配置

- **Argos**：已有 beam2/beam4 证据未解决保义问题；repetition penalty 1.05/1.0 单因素对照已准备，尚无新推理。当前启用中英双向，不等于整个生态语言包已接入。
- **Argos 安装合同**：CI457 两归档共 145,224,423 字节，全 ZIP 声明量共 171,778,261 字节。待集成 archivePin 严格绑定归档 SHA、压缩和展开量；这是项目审核固定值，不是上游签名。Python/Linux 新装同盘推导预算为 2,531,595,196 字节，缺 pin 保留保守路径；旧库存与 runtime 依自身完整性和实际复制预算，不冒称被新 pin 认证。Windows 同步身份与写出限制，不能把 UI 已知下载量直接当足够安装预算。真实安装须在审查通过后重新核空间和内存，不以压缩包小为由绕过准入。
- **Hy**：实际配置为官方 instruction+greedy、同 instruction+固定 seed sampling、greedy+保义 instruction。前两者固定四句开发子集未明显改善；第三种覆盖八条已见难例，独立复核为 1 条明确严重错误、3 条未决、4 条未见严重错误。承诺、主体及范围风险未闭合，本轮不采用。
- **证据缺失须明示**：旧完整八句 A 曾因 60s 截止中断，四句子集不能覆盖失败；环境重置后旧临时 A 原件丢失，派生对照不冒充原件。保义 B 八句的两份原件仍在持久目录。后续源码和不可再生证据只存持久工作区。
- **Qwen3-0.6B Q8_0**：官方非思考固定采样与原生 greedy 两套，各八条均真实 EOG 完成；仍有主体、数量、日期或承诺改变。greedy 仍有 6 条明显严重问题，不进行第三套盲扫。两套改变的是整个解码配方，不宣称单参数因果。
- **Qwen2.5-1.5B Q4_K_M**：官方普通 ChatML、相同八句和保义指令、原生 greedy。八条均以实际 EOG 151645 完成，总 50.073s，峰值地址空间约 1.205GiB；独立复核为 3 条严重错误、2 条明确改义/遗漏、3 条未见重大错误。周五改为周初、改票请求改成已改成功、周二改为下周五，不能替换 Hy。原生 EOG 集与官方 generation_config 有差异，但八条实际均使用共同终止 token，未据此虚构提前截断。
- **Qwen3-1.7B Q8_0**：已核官方固定 revision、1,834,426,016 字节及 SHA，模板非思考实际分支与八条输入逐字核对，原生 probe 不改；单套 greedy 八条均以实际 EOG 151645 完成，总 87.096s，峰地址空间约 1.949GiB，零重试、进程退出及身份保持已核。独立语义复核进行中；能运行不代表质量合格。
- **统一限制与采用条件**：CPU2、地址空间2.5GiB、context1024、output192、单请求60s、总600s及有界清理，失败停止、0重试，生产身份不变。保存模型身份、模板、参数、原响应、失败和退出证据；逐句复核否定、数量、主体、条件和承诺。八条是已见开发集，局部改善只支持继续验证，不直接改默认。
- **其余方向**：MADLAD 初始化已核超出现预算；M2M100 的 CT2 支持不代表转换峰值可控，现无已证明的预算内转换路径；TranslateGemma4B 暂缓资源与条款核查。未实测的候选不写成质量失败。协议见[测试方法](testing.md)，共同要求见[产品缺口](../product/README.md#当前共同开发缺口)。

## 每条线都要做的维护

1. **保持原行为与安全门。** 遵守 [AGENTS](../../AGENTS.md) 和产品基线；未知焦点、输入法、目标身份或结果继续拒绝/隔离。产品许可期限不放宽；外部准备与产品计时分开，不能靠重试、跳过失败或降低断言制造通过。
2. **代码、测试、文档一起收尾。** 修改行为时逐项判断旧测试：有效则保留，假设过时则更新，需求/接口真正退役才删除；修测试须说明保留的安全行为。失效接口、重复逻辑、无用文件和引用一起清理，不为整理重写全库。
3. **证据分层。** 区分代码实现、本地检查、当前提交 CI、用户真机。编译不等于 GUI，采集完成不等于质量合格；缺陷、测试问题、缺诊断、未支持功能和真机待验分别标记。
4. **失败后换取新证据。** 相同失败再现而无新证据时，先写清假设、观察位置和下一判据，不盲目重跑，不让一条线停止无关工作。确需新增权限或用户选择时指出具体动作，其余独立工作继续。
5. **维护唯一入口。** 实质结果或安排变化时更新本页；关闭后删掉执行细节，将有效限制放回平台说明。发布后核候选、CI和包一致，不新增阶段快照。文档冲突按实际提交及证据校正，不任选更乐观的结论。
