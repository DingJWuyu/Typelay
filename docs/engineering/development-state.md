截至 **2026-10-29**，正在 `work/linux-usability` 重构原生 Windows WPF、Linux GTK 设置与合作浮层。`trunk` 已合入重构前的 `438c497`；`main` 未改。此开发候选不是稳定发布或已验收体验包。

既有功能、新术语管理、按应用设置、即时保存、外观、中英界面、搜索、快捷键录制与撤销均属于实现范围。更多语言、新风格、设备选择、模型常驻与更新只提供真实标明不可用的前端，见[能力缺口](../design/implementation-gaps.md)。原型中的模拟桌面和定时译文不进入产品。

## 验证状态与当前阻塞

首个重构检查点为 [`8d5eb77`](https://github.com/DingJWuyu/Typelay/commit/8d5eb77bace13d1bdceb27108297a579e1d2fb32)，[对应 CI](https://github.com/DingJWuyu/Typelay/actions/runs/40827025187) 的 Linux Index 正式模型包生命周期通过。共享 lint、Windows 测试分析器、字体分发文件集合与 GTK4 字段声明检查失败；修补候选需重新跑精确提交 CI，不能沿用旧提交结论。

当前本地验证包括真实 Chromium 73 项交互合同、Linux GTK 设置持久化/术语和应用撤销/语言/托盘流程，以及共享运行时、协议、worker 与分发合同。Windows 托管编译通过不等于 WPF 实际运行。两端完整包、原生合作模块和最终界面状态仍在验证，视觉差异不能计为一比一完成。

Index 能力放行表保持关闭。真实固定样本存在权限语义和严格数值边界错误；独立留出集首个普通请求触发既定 60 秒单请求超时，后续样本未运行。模型包生命周期成功、协议通帧、术语成功保存均不构成翻译质量通过。异常诊断保留原失败，不提高期限、不修改提示来覆盖该结果。

## 持续约束

输入来源、焦点身份、IME 状态、租约、接受资格、写回与 Undo 安全条件不因界面重构而放宽。物理按键、真实 IME、UIAccess 和第三方应用需要各自证据，软件注入不替代可信来源接受。新空库存默认 Index，保留已有 Argos/Hy、显式选择及方向；不自动下载或替换，修复失败保旧代。

字体为随包 OFL Inter 与 Source Serif 4；CJK 仍由平台回退。模型权重不进入源码或产品运行包。当前未更新稳定版、`main` 或既有体验推荐。
