## 后续验证

Windows 下载正文现在受原单次下载期限约束；Linux 测试状态文件采用完整写入后原子替换，避免 GTK 主线程耐久同步。原准备场景在 CI534/535/536 通过，Linux 原探针在 CI534 通过，下载期限、浮层租约、过期拒绝及写入安全断言保持；不能据一次成功倒推上一轮网络或调度故障的唯一原因。

Windows 新候选安装不再额外等待下一次轮询，浏览器允许一槽元数据预取与上一批准 ACK 重叠，批准仍串行；原许可期限、旧代撤销、来源及写回安全门保持。CI536 的原 F7/Tab、四个晚 ACK 分支及自有 trace 清理回归均通过；浏览器原 Direct 和后续场景实际通过。此结果不保证任意负载下始终及时，也不能倒推较早导航中止的唯一原因。

当前定位源激活测试的窗口遮挡：17 项都在首次点击前命中同一个非导航目标的终端窗口，尚未发出测试输入；现有证据不足以归属该窗口。只补充有界进程与窗口身份诊断，不关闭未知窗口、强置顶或放宽焦点断言。本次有界诊断若仍无法归属，或确认是不能安全操控的运行环境，则转独立桌面隔离后验收，不继续堆叠探针或以随机重跑代替修复。

物理 Tab 验证包的原合同准入和打包 smoke 已通过，不代表物理键验收。Notepad 的真实可信接受输入仍需独立桌面验收；已有接受提示和软件注入不能替代。后续结果绑定各自精确提交，未运行项不计为通过。

## 仍约束交付的产品边界

### 翻译质量：有界实验，不盲目扫配置

**模型生命周期不等于质量放行。** 已过的普通及结构请求不证明所有语言、长文本、风格、术语或性能均满足需求。Index 使用完整原源一次推理；产品仅在严格结构校验后恢复原源的全请求 SP/TAB 边缘及换行类型，不修补语义，也不宣称与原始评测输出完全等价。固定配方与资源限制见[工程架构](architecture.md)。

### 平台与发布

- **平台安全门保持。** 输入来源、焦点身份、IME 状态、接受资格、写回及 Undo 仍按原合同验证；未知状态保守拒绝。物理按键、真实 IME、UIAccess、第三方应用与完整 GUI 验收各需自己的证据。
- **发布范围保持。** 开发分支 CI 通过的局部项目不自动晋升稳定版或体验推荐。平台使用与当前支持范围见 [Windows](../platforms/windows/README.md) 和 [Linux](../platforms/linux/README.md)。
