## 验证状态与当前阻塞

当前远端检查点为 [`eb79ad0`](https://github.com/DingJWuyu/Typelay/commit/eb79ad0c1cd6ceff055a8120037ffdbe01b8c9ef)，[对应 CI541](https://github.com/DingJWuyu/Typelay/actions/runs/40830336852) 的共享检查与 Linux Index 正式模型包生命周期通过，已结束且整体失败。Windows 实际 App 合同有 33 项失败，涉及新布局测试迁移、对比度、草稿/菜单交互和几何问题；Linux 的部分原生合作及真实模型桌面测试也失败，正在按原件修复。Windows Index 的准备提示器误拒新四导出载荷，严格旧/新载荷配对修补已完成本地回归，仍需新提交 CI 验证。Windows 真实 Notepad 与 Hy 设置流程分别停在发现设置窗口和首次设置；后续场景未运行。已定位旧 fixture 在新首启教程仍显示时等设置窗口，正在迁移为真实四步教程，再走托盘和设置公开路径。

CI 在部分失败后继续执行后续步骤；进入打包不能证明前序成功。逐项检查实际 `conclusion`、结构化结果和精确源码身份。
已发布检查点的本地验证包括真实 Chromium 73 项交互合同、Linux GTK 设置持久化/术语和应用撤销/语言/托盘流程，以及共享运行时、协议、worker 与分发合同。Windows 托管编译通过不等于 WPF 实际运行。当前 Linux 修补还通过真实 AT-SPI 八页导航、模式即时保存、快捷键录制与还原；不替代真实模型路径验收。两端完整包、原生合作模块和最终界面状态仍在验证，视觉差异不能计为一比一完成。

Index 能力放行表保持关闭。真实固定样本存在权限语义和严格数值边界错误；独立留出集首个普通请求触发既定 60 秒单请求超时，后续样本未运行。模型包生命周期成功、协议通帧、术语成功保存均不构成翻译质量通过。异常诊断保留原失败，不提高期限、不修改提示来覆盖该结果。

当前待发布修补已覆盖 WPF 几何、对比度、菜单焦点和旧交互实例，以及 Linux 八页导航、即时保存和实际控件录制流程。当前浏览器修补候选本地真实完整 74 项通过。此前全量出现一次持键激活与预期拒绝不符，以及接受路径失败；单次旁观诊断与本次通过均未解释原失败，不能标记根因已修复。保留有界可信事件与命令证据，后续正常全量继续核查，不刷新授权或放宽时限。
