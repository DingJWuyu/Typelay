TypeLay Windows 0.2.0 开发集成包

先完整解压，再双击 TypeLay.exe。

重要：
1. 双击 TypeLay.exe 启动。客户端主要位于系统托盘的 T 图标，可能在折叠图标区域。
2. 本机 app 目录已经准备好客户端和 .NET 运行时；没有 app 的源码包才进入自动构建。已有私有 SDK 可以复用。
3. 设置中“检查并准备”安装本地运行组件；有效的本机 Argos 1.9 中英模型会复用，缺失时才下载。通过本机自检后才能翻译。
4. 默认仅提供候选预览/编辑/复制，实验 Tab 写回关闭。
5. 实验写回仍有非原子竞态和已拦截 Tab 被消耗的风险，只能用已备份测试文本。
6. Windows 构建、真实中英双向模型以及 Edge 教程单行、多行翻译预览已验证成功。此前无浮层的输入服务崩溃已经修复。
7. Tab 写回、人工编辑、真实输入法和独立网站仍需逐项验收，结果见 VERIFICATION_STATUS.md。

备用入口：Start-TypeLay.cmd。
首次失败记录：%LOCALAPPDATA%\TypeLay\build-logs
不需要管理员权限。不要为运行开发版关闭系统安全功能。
完整说明在 README.md、VERIFICATION_STATUS.md 和 docs 目录。
