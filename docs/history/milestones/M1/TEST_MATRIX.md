本文件是用例与验收清单，**不是通过报告**。M1 的 C# runner 已编写但本轮均未运行。结果以具体 run.json / runner 输出为准，不能根据用例数量推断通过率。

## 原生 runner 的限制

它通过明确的 Win32 消息执行产品 adapter 的读写，不模拟真实物理 Tab。最后 `BM_CLICK` 只用来证明 Submit 计数器有效，不能解释为 TypeLay 自动提交。两个 fixture-IME 测试通过 SetProp 注入状态，是合成接口检查，不是真实输入法验证。

截图或 Computer Use 注入键可作辅助操作记录，但若产品按 injected 规则放行，则其结果不能替代真实键盘 Tab 验收。

## EDIT-01 真机操作记录模板

环境：Windows build / .NET runtime / Edge build / IME profile / 显示器比例 / 新源码哈希。

步骤：在 A 用测试中文获得真实译文；点击译文中段；键入两个词；拖选其中一个词；Delete；连续 Backspace 两次；直接继续键入；按 Tab；确认 OS 真正聚焦 A；停顿后再 Tab。重复一次不等待的连续 Tab，并重复一次鼠标返回。对 B 的中文选区重做全流程。

检查：浮层未消失；编辑器未重建；焦点未丢；第一次 Tab 未写回；第二次只替换预期范围；原文其余部分/emoji 保留；caret 正确；Submit count=0；无 toast；自动翻译未覆盖人工草稿。

## 证据失效规则

有源码改动必须生成新指纹并重跑受影响测试。没有模型权重、实际 OS、真实输入或字段 provider 的证据时标记 not-run。测试 runner 退出 0 只能签署它输出的用例集合；不能用来签署“Windows MVP 全部通过”。
