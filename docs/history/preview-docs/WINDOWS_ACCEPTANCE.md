# Windows 验收记录模板

本文件是未填结果的验收模板，全部状态为 **NOT RUN**；已执行结果另见 [最新验证记录](../VERIFICATION_STATUS.md)。每个测试记录 Windows build、浏览器版本、输入法版本、DPI/显示器、客户端/源码哈希、模型锁、步骤与观察。不得把本模板、自动脚本或模型安装自检当作真实链路证据。默认只读验证先行；实验写回只使用已备份测试文本。

产品目标是自动跟随当前聚焦的普通文本输入框。应用名称和教程字段仅用于覆盖不同控件实现，不构成支持名单；验收不能要求用户先判断输入框是否“合格”。工具禁止操作某个场景时，选择其它允许的代表性场景并如实记录剩余覆盖。

## A. 构建、准备、正常启动

完整解压，双击启动器；验证私有 SDK 下载校验、失败后的停止与重试；运行 solution 和所有逻辑测试；从首次设置安装组件与模型，记录两个方向的实际 CPU 自检；退出后再次启动确认不重建。验证重复启动只保留一个托盘，退出后不留 Broker/worker/hook。断网状态下已安装模型仍可推理。

## B. 第一条真实应用闭环

教程 `fixtures/browser/index.html` 可以作为基础对照，再选独立网站及桌面应用的普通输入框，覆盖单行、多行、无标签、可编辑文档及不同框架。记录其实际能力和结果，使用无敏感内容的测试字段；不能先筛掉失败控件，再把剩余样本宣称为通用支持。仅 fixture 成功不能通过该项。

输入“你好，我想确认一下明天下午的会议时间。”，候选须来自实际模型。浮层出现不得抢焦点或推动页面。只读默认下 Tab 正常交还应用。实验模式下候选有效时按一次物理 Tab，结果只能替换当前字段/原选区，提交计数保持零，光标到替换末尾，浮层收起。不接受旧结果，不进入下一个可点击提交按钮后触发任何激活。

## C. 持续编辑与两阶段 Tab

点击译文中部，选择部分词语、连续修改、粘贴和换行，观察原生光标/选区不跳动。保持点击进入后自动更新冻结。第一次 Tab 只返回原输入框，下一次 Tab 接受；两次间隔不限速度。鼠标返回同样进入人工候选待接受。按住 Tab 验证重复与 keyup 所有权，第一次返回的重复事件不得立即接受。

人工修改后原文末尾追加：保留人工前缀，新增部分继续翻译；修改原文已有字符：人工候选失效并重翻。翻译失败/过期期间 Tab 不接受旧文。切换字段或 Alt+Tab 不保留旧候选。

## D. 真实中文输入法

使用系统微软拼音，在源字段和浮层编辑器中分别验证拼音输入、翻页、选词、Backspace、Esc 取消、Enter/空格提交、Shift 中英文切换、composition 期间按 Tab、候选窗口打开时点击浮层、提交后立即 Tab。捕获 composition=Unknown 时保持拒绝接受。不能用 DOM composition 脚本或固定 sleep 代替真实输入法。

## E. 安全与拒绝

敏感元数据/password/OTP/CVV/只读/代码/终端/地址栏不得读取正文或显示误导浮层。无标签普通输入及明确可编辑 Document 应自动发现，不能因缺少标签或使用 contenteditable 直接排除。仅有文本范围而无写值接口的富文本不能降级为整框 SetValue；输入法状态未知只能明确显示只读预览。停用/排除无 UI。

焦点快速切换、用户按 Tab 同时脚本改变原文、选区拖动、原文改变、窗口被关闭/复用、broker 卡住或崩溃均不得写错目标或覆盖新文。**当前 B-01 已知存在竞态，B-03 的通用编辑后端也未完成，不得在此表勾选安全或通用输入通过。** 必须修复后增加定向竞态回归和真实按键记录。

## F. 视觉、定位、性能

与保留原型对照浅/深、100–200% DPI、左右/上下显示器、负坐标、副屏任务栏、窗口移动/缩放、页面滚动、离屏恢复、长文本内部滚动/展开。记录实际延迟、输入是否卡顿、CPU/RAM；性能数值应来自测量。

## 发布门槛

全部第一步链路、B-01 关闭与真实中文输入法底线通过，才可将实验接受转换为默认能力。第二步还要求选区/人工编辑/连续编辑/两阶段 Tab 全通过；B-03 未关闭时不能宣称通用普通输入完整可用。先生成预编译自包含开发包再分发；不可连续依赖最终用户反复构建未知状态源码。验收记录可以诚实保留失败项，不能修改 PoC 历史结论。
