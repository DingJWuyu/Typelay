# 实现结构与维护边界

## 数据流

原应用 → 独立 UIA Broker → 私有有界二进制帧 → App 协调器/Core 状态机 → 本地 Python 推理进程 → 带版本候选 → WPF 浮层。实验接受操作经 Hook 原子短效许可 → Core WritePlan → Broker 重读/拒绝或写入/核验回执。默认禁用接受许可。

发现入口是当前聚焦的普通可编辑控件，不依据特定应用、浏览器、页面或自然语言标签。应用只是用于覆盖不同控件实现的验收样本。许可门本身的原子消费不代表目标文本写回原子性；B-01 及通用编辑后端缺口 B-03 仍开放。

## 职责

- **Core**：纯状态机，方向/会话版本、快照、UTF-16、候选新鲜度、编辑冻结、追加策略、写回前后状态、单目标隔离。与 WPF/模型包/UIA 无耦合。
- **Protocol**：最大 256 KiB、32 位小端长度前缀 JSON、严格序号/类型检查；字段允许策略；通过实际选区前缀映射 UTF-16，UIA Character 单位只作搜索提示。
- **Broker**：MTA COM，当前字段的敏感元数据筛选先于文本 getter；UIA TextEdit/IMM 状态观测；整框与选区观察；原控件身份/进程生命周期/窗口/版本检查；定向 SetValue 和写后核验。已知组合态只提供已提交前缀；未知状态可提供普通字段值的只读预览，不能颁发接受许可。未知写回结果进入隔离；阻塞由父进程超时终止。
- **App**：Dispatcher 协调与最新任务调度、持续存在的原生编辑器、托盘与设置、主题、当前用户启动项、Hook 镜像、安装流程。Hook 回调不执行 UIA/网络/推理/磁盘调用。全局焦点事件使旧许可失效。
- **worker**：私有 stdin/stdout 管道，Lingua 检测、SentencePiece、CTranslate2 CPU；模型常驻；没有下载路径和历史存储。日志只有错误代码。未加载模型时失败退出；从不回退成字典 Mock。

App/Broker/worker 使用独立进程。子进程放入 Windows Job Object，父进程退出时结束；Broker token 只通过继承的私有进程环境传递，不开网络端口。该边界用于可靠性和最小暴露，不构成对同用户恶意进程的完备安全沙箱。

## 并发与时序

UI Dispatcher 为 Core 唯一写入者。模型任务串行，结果必须属于当前会话、配置和对应原文版本。追加输入可保留旧前缀的显示预览，只有完全对应最新原文且输入法状态可靠的候选才可接受；换目标或修改已有文字会使旧结果失效。默认 debounce 300 ms，持续输入最大等待 500 ms、观察新鲜度 150 ms、许可 100 ms；实际刷新还受读取及模型耗时影响，不提供性能保证。UI 不以“已发出返回焦点请求”认定返回完成，需要新的真实源焦点观察。

快照的 PreviewText 与 CommittedPrefix 语义不同：前者来自未知输入法状态下的普通字段值，可能含未提交字符；后者仅来自已知组合态的已提交前缀。两者都只能显示，快照 Text 不因此取得写回资格。预览在无翻译、推理失败及隐藏后新输入时仍可重新调度，不会将只读状态升级为候选。

进入人工编辑不会重建 TextBox，不会用自动候选覆盖编辑控件内容。原文/译文家族内切换保持会话；离开后清理候选和编辑 undo 引用。暂停/排除/超时使许可失效。未知写回禁止盲目重试，避免重复覆盖或向新窗口输入。

## 安装与分发

启动器只做定位和执行明确随包的 PowerShell 脚本，无 CRT/第三方依赖。首次私有 SDK 校验使用微软 releases 元数据 SHA-512；CPython 包校验使用 NuGet catalog SHA-512；wheel 使用 PyPI 版本元数据 SHA-256。Argos 索引无所用档案摘要，首次模型真实性依赖官方域名 HTTPS，记录的摘要用于后续本地完整性，不能宣称上游摘要锁定。

所有 Python wheel 是固定版本的预编译 Windows x64 wheel，仅展开到私有目录，没有用户级 pip 安装或运行任意 sdist setup.py。安装目录使用 staging/promote；组件重装失败时模型可用状态仍关闭。模型自检发生在新模型目录正式激活之前。依赖最终 URL/哈希在首次安装后落地，分发包不含完整预解析二进制 lock。

## 可维护性约束

外部 API 只在 platform/Broker/基础设施中出现；视图不直接写目标应用；协议不传任意远程命令；使用单个当前会话；日志无源文本；无全局快捷键模拟后备；无云端翻译后备。未实现功能明确禁用。保持 `archive/M1` 只读历史语义，后续修复应修改当前实现和对应测试。

下一发布门槛为：解决原子写回/Tab 所有权问题，补齐通用编辑后端，并取得对应真实浏览器、IME 与多屏证据。预编译开发客户端已生成并安装，不代表已通过发布门槛；结构检查与专用适配器测试不允许跨越该门槛。
