TypeLay · 实操教程与回归页

仅使用测试文本。此页不是 TypeLay 客户端，没有翻译 Mock，不接入模型。浏览器支持、真实物理 Tab 和真实输入法必须分别验收。页面标识不构成可信来源证明。

先在设置中检查并准备本地模型。默认只读预览；下面的 Tab 替换测试需在「常规」开启实验性写回，并等浮层显示“Tab 接受译文”。

  1. 聚焦 A，修改测试文字，等待真实本地译文。按 Tab 应只替换文字，提交次数保持 0。
  2. 点击译文并修改，第一次 Tab 返回 A；第二次 Tab 接受。也测试用鼠标返回 A。
  3. 点击下方“选择 B 中的中文”，验证选区外内容与 emoji 不变。
  4. 切换真实中文输入法，分别测试候选、提交和 Esc 取消。未提交时 Tab 应交还输入法。

此页通过仍只代表 fixture 结果。还需在独立真实站点的普通输入框完成同样操作。
